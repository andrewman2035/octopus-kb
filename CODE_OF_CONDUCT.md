# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussions about the work. Harassment,
personal attacks and sharing other people's private information are not accepted in issues, pull requests or any
other project space.

Report unacceptable behaviour privately to the maintainers via GitHub's **Report a vulnerability** form (Security
tab) at <https://github.com/andrewman2035/octopus-kb/security>; it is private, and it is the project's only private
reporting route. Reports are handled confidentially, and the maintainers will act as the Covenant's enforcement
guidelines describe.
